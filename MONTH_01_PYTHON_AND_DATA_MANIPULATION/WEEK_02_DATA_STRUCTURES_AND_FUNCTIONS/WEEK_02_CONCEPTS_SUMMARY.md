# Week 2 Concepts Summary: Data Structures and Functions

## Topics Covered
1. **Core Data Structures**:
   - `list`: Ordered, mutable collections.
   - `tuple`: Ordered, immutable records (used for coordinates and composite deduplication keys).
   - `dict`: Key-value mappings for structured records.
   - `set`: Unordered unique collections for fast `O(1)` membership checks and deduplication.
2. **Functions & Scope**: Modular, type-annotated functions with default arguments.
3. **Lambda Functions**: Anonymous inline functions combined with `filter()` and `sorted()`.
4. **Recursion**: Base-case + recursive-step problem decomposition (`recursive_sum`).
5. **List Comprehensions**: Concise, readable transformations and conditional filtering.

## Deliverables Implemented
- `data_structures_and_transformations.py`: Demonstrates all four data structures, sum of squares, recursion, lambda filtering, and list comprehensions.
- `data_cleaning_client_project.py`: Deduplicates and filters messy client transaction records using sets, dictionaries, and validation rules.
