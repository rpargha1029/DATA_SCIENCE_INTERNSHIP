# Month 1: Python Basics and Data Manipulation

## Objectives
- Learn Python programming basics (variables, data types, operators, conditionals, loops).
- Master Python data structures, functions, lambdas, recursion, and list comprehensions.
- Practice data manipulation with NumPy and Pandas.
- Implement data visualization dashboards using Matplotlib and Seaborn.

- Python 3.10+
- NumPy, Pandas, Matplotlib, Seaborn

## Learning Outcomes
- Confident use of core Python control flow, functions, and data structures.
- Vectorized numerical computation with NumPy and tabular cleaning/aggregation with Pandas.
- Communicating quantitative patterns through multi-panel Matplotlib and Seaborn visualizations.
