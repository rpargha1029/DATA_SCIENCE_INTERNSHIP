# Week 1 Concepts Summary: Introduction to Python Programming

## Topics Covered
1. **Variables & Data Types**: `int`, `float`, `str`, `bool`, and type casting (`float()`, `int()`, `str()`).
2. **Operators**: Arithmetic (`+`, `-`, `*`, `/`, `**`, `%`), comparison (`==`, `<`, `>`), and logical (`and`, `or`, `not`).
3. **Input / Output**: Reading user input via `input()` and formatting output with Python f-strings (`f"{val:.2f}"`).
4. **Conditional Statements**: Branching logic with `if`, `elif`, `else` for validation and menu routing.
5. **Loops**: `for` loops for iterating over sequences (temperature lists, station dictionaries) and `while` loops for interactive menus and index-based traversal.
6. **Exception Handling**: Catching `ValueError` and `ZeroDivisionError` to keep CLI scripts resilient.

## Deliverables Implemented
- `temperature_converter.py`: Converts between Celsius, Fahrenheit, and Kelvin (interactive + `--demo`).
- `calculator.py`: Arithmetic calculator with error handling (interactive + `--demo`).
- `average_temperature_client_project.py`: Aggregates multi-station weekly temperature data, computes min/max/average, and flags threshold alerts.
