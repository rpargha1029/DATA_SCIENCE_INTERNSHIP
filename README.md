## Quick Start

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
2. **Explore & Learn (Self-Paced)**:
   Each month's folder is self-contained with modular `src/` scripts, 12-section Jupyter notebooks, and a `README.md` explaining concepts, data preprocessing, and modeling choices.
3. **Download External Kaggle Datasets (Months 2–5)**:
   Large raw CSVs and credentials are excluded from Git via `.gitignore`. Follow each month's `README.md` to download the required Kaggle dataset into its `data/` directory.
4. **Verify Before Monthly Submission**:
   Follow [GITHUB_SUBMISSION_CHECKLIST.md](./GITHUB_SUBMISSION_CHECKLIST.md) before pushing to GitHub and submitting on Google Classroom by the 20th.
